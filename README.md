## 📋 项目简介

这是一个精心整理的 Clash 规则配置集合，包含多种常用服务的分流规则，帮助您实现智能网络访问。

## 🚀 规则文件

- **rules_merged.yaml** - 完整的 Clash 规则集合
  - 更新日期：2026年3月21日

## 📁 规则排序

规则按照以下优先级顺序排列：

1. 自定义规则
2. AI服务
3. Reddit
4. TikTok
5. 电报消息
6. 广告拦截
7. AdBlock
8. 应用净化
9. 奈飞视频
10. 微软服务
11. 游戏平台
12. 国外媒体
13. 关闭加速
14. 节点选择

## 📝 使用方法

1. 下载 `rules_merged.yaml` 文件
2. 将规则文件导入到您的 Clash 客户端
3. 根据需要调整规则组开关
4. 享受智能分流体验
